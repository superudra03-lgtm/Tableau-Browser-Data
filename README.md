Web Browser Data Analysis

This project focuses on analyzing user behavior across different web browsers using a dataset of online session activity. The goal is to understand how browser choice influences user engagement, browsing patterns, and spending habits.

The dataset includes information such as the browser used during each session, time spent on the website (in minutes), number of pages viewed, amount spent in dollars, and the day of the visit. By examining these variables, the analysis identifies patterns and differences in how users interact with the site.

Key findings from the analysis show that Firefox users are the most engaged, with the highest average time spent and the most pages viewed per session. Internet Explorer users contribute the highest total revenue due to having the largest number of sessions, even though their average engagement is lower. Users on other browsers have the highest average spending per session, indicating a smaller but more valuable customer segment.

The project was completed using Microsoft Excel for data preparation and calculations, and Tableau for data visualization and dashboard creation. Visualizations help highlight trends and make it easier to compare performance across browser types.

The purpose of this project is to generate actionable insights that can support better decision-making in areas such as marketing, website optimization, and customer targeting. By understanding how different users behave, businesses can improve user experience and increase overall revenue.
